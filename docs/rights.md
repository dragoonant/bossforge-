# Rights findings (recorded 2026-10-28, before the first line of engine code)

## Rights holders

| Holder | Owns |
|---|---|
| Brotherwise Games, LLC (Torrance, CA) | Boss Monster: the game, rules, card names and text, the pixel art, the "Boss Monster" trademark and logo |

Character names on the cards (Draculord, King Croak, ...) are Brotherwise's own creations; there
is no second licensor in the Base Set.

## Precedent (dated, not permission)

- An officially licensed digital Boss Monster existed (2014, mobile and Steam). A fan client sits
  next to a licensed product, which is the case publishers act on most.
- A Steam Community Tabletop Simulator item for Boss Monster appeared in a 2026-10-28 web search.
  Takedown history was not researched. **This is not permission; it is the current state of the
  world, dated 2026-10-28.**

## Where this project sits, stated plainly

There is no published permission for a rules-enforcing digital client reproducing Boss Monster's
cards. "Tolerance is not permission, and it is revocable at will." No fair-use argument is relied
on and none is claimed. The project stays non-commercial, clearly unofficial, uses no official
art, logos or frames, keeps names and text in one deletable file, and is withdrawn on request
(`docs/takedown.md`).

## Consequence

The owner chose public GitHub Pages after this concern was stated once (PLAN D6).
